# EV Charging Analytics Platform Backend

Backend аналитической платформы для управления сетью зарядных станций.

Платформа предоставляет REST API для построения аналитических Dashboard, расчёта бизнес-метрик, мониторинга инфраструктуры и финансовой аналитики.

---

# Возможности

На текущий момент платформа включает следующие модули:

- Summary Dashboard
- Finance Dashboard
- Monitoring Dashboard *(в разработке)*
- ETL Monitoring *(в разработке)*
- CAPEX / OPEX *(в разработке)*

# Архитектура проекта

Backend построен по многослойной архитектуре.

```text
HTTP Request
        │
        ▼
Router
        │
        ▼
Service
        │
        ▼
Repository
        │
        ▼
PostgreSQL
```

Каждый слой отвечает только за собственную область ответственности.

- **Router** — обработка HTTP-запросов;
- **Service** — бизнес-логика;
- **Repository** — получение данных из PostgreSQL.

# Docker

Backend запускается в контейнере **chargeflow_api**.

На текущем этапе разработки PostgreSQL работает на хост-системе и подключается через Unix Socket.

В дальнейшем база данных будет вынесена в отдельный Docker-контейнер.

# Dashboard

На данный момент реализуются следующие аналитические Dashboard.

### Summary

Основной аналитический экран.

Содержит:

- KPI показатели;
- графики;
- рейтинг станций;
- сравнение периодов.

---
### Finance

Экран финансовой аналитики.

Предназначен для анализа финансовых показателей сети зарядных станций.

Содержит:

- ключевые финансовые показатели;
- структуру расходов;
- показатели прибыльности;
- финансовые графики;
- показатели эффективности бизнеса.
---
### Investments

Экран управления инвестициями.

Предназначен для ввода и анализа капитальных и операционных расходов.

Содержит:

- учёт CAPEX;
- учёт OPEX;
- ввод инвестиционных расходов;
- историю изменений расходов.

### Monitoring *(в разработке)*

Мониторинг состояния инфраструктуры.

Планируется:

- состояние станций;
- сервисные обращения;
- ошибки завершения сессий;
- состояние интернет-соединения;
- расходы на обслуживание;
- прогноз ремонта оборудования.

---

# Принципы разработки

При разработке backend используются следующие правила.

- Router не содержит бизнес-логики.
- SQL располагается только в Repository.
- Service отвечает за расчёт и агрегацию данных.
- Dashboard состоит из независимых Widget.
- Архитектурные решения фиксируются в ADR.
- API документируется отдельно.
